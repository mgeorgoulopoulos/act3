# Restoration notes

ACT3 was recovered from a surviving D3D9 source snapshot and the original release
assets. The aim was to make that source run again, then provide a distinct
anniversary treatment. The source snapshot is preserved as the first Git tree;
it is not asserted to be the exact source used to build the released 2004 binary.

This is a curated technical account, not a transcript of development sessions.

## From one flower to the full demo

The first visible milestone was a plain OpenGL window, followed by the original
flower geometry in wireframe. A temporary geometry preview established that the
asset and platform setup worked. It was replaced by the historical loader and
rendering methods as the compatibility layer acquired buffers, transforms,
materials, scene batches, frustum tests, reflection mapping and billboards.

That distinction guided the restoration: a preview could help diagnose a problem,
but the restored scene had to come from its historical C++ logic.

The complete sequence was integrated through a new host: Space, Shadow,
Eggplants, Greetz and Credits. Textures with identical names are scoped to each
scene so that a replacement for one part cannot silently change another.

## Visual reference and fidelity

The original executable was captured across the production. Those references were
used to check brightness, camera orientation, overlay timing, feedback, reflection
mapping and transitions. The original flow and soundtrack remained the reference.

Some important recoveries:

- D3D row-vector transforms and its clip-depth convention are mapped explicitly to OpenGL.
- File-format chunk widths use fixed-width integers where the disk format requires them.
- Path separator handling belongs in the loader rather than scattered edits at call sites.
- The 32x32 vortex grid between Space and Shadow uses the original deformation arithmetic.
- Shadow's normal presentation is sharp; strong defocus in the anniversary edit is intentional and timed.
- Greetz keeps its original staggered arrival and independent squash/stretch cycles,
  including participation in feedback. Widescreen placement changes do not replace the animation.
- The final aspect-ratio presenter disables inherited texture generation and every
  secondary fixed-function texture unit. This avoids the Pioneer cubemap contaminating
  the fullscreen presentation quad with radial streaks.

The Party path still exhibits the character of the original renderer, including
frame-rate-dependent feedback. The goal is recognizability and continuity, not a
claim of bit-exact hardware emulation.

## Art direction for the anniversary edition

**Space:** preserve the plaque illusion before revealing actual geometry. Let
orbital detail shots and the departure tell the story, retaining the two-layer
starfield parallax. Replace low-resolution engravings and overlays while keeping
the original graphic identities. The grading aims for the wonder and darkness
of a space documentary.

**Shadow:** keep the psychic intensity. A dolly zoom changes the environment around
a comparatively stable figure. Native-resolution focus, abrupt negative accents
and selective depth-based grading keep the figure readable. The round negative
particle core becomes an organic dark presence; the billboard rays are restrained.

**Eggplants:** the surrounding circuitry is elaborate, yet the flowers' attention
belongs entirely to the light. Enter the forest while watching that light. Use
parallax, occlusion and restrained FOV accents; blend back into the original camera
for the harp passage and the final approach to the egg. The circuit reconstruction
uses finer traces rather than simply enlarging old lines.

**Greetz:** an ancient, ambiguous organic form against disorienting feedback. Keep
the blob separate from its background, with DNA and group names as neon accents.
The finer surface is still generated by the original marching-cubes algorithm.

**Credits:** preserve the playful reflective tube and particle field, make it fill
the widescreen composition, and let the green reflections read clearly. The final
card uses static, crisp red serif lettering with an optical-film glow.

Selected new artwork was created with generative-image assistance; procedural and
typographic reconstruction was also used. The original author directed the edit
and reviewed the results alongside the music.

## Shared technical choices

- A D3D9-compatible API subset over OpenGL, rather than invasive rewrites of every scene.
- Build-tree adapters to keep modern host integration and optional hooks outside historical files.
- Native Windows UI; Linux terminal UX with X11/GLX and XRandR display control.
- miniaudio for MP3 playback on both platforms, with live FFT analysis over decoded audio.
- Per-part LUTs, with extra depth-aware corrections where a global grade is insufficient.
- Native-resolution anniversary rendering and aspect-preserving black padding.
- Fine grain and optical irregularity measured against a fixed 4000-pixel-wide reference,
  so changing output resolution does not redefine the artistic displacement scale.

## Current validation boundary

Windows Debug and Release builds have been exercised. A publication checkout is
built separately to catch missing assets and reliance on local-only changes.
Screenshots in this repository are renderer captures and a cropped application
window, not mockups. Screenshot JPEGs are reduced for the GitHub page.

Linux is kept in the CMake/platform design, but has not yet been compiled or run
as part of this restoration. It remains an explicit validation task for Linux testers.

For numerical preservation claims, use the [reproducible source report](code-provenance.md).
